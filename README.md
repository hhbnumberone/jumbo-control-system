## 1. 凿岩台车组成与钻臂驱动装置原理

### 1.1 整机组成

凿岩台车（液压钻孔台车）主要由以下子系统构成：

| 子系统 | 内容 | 驱动方式 |
| --- | --- | --- |
| 底盘 | 履带/轮式行走，铰接转向，支撑整车 | 液压马达行走，柴油机或电机驱动泵站 |
| 动力系统 | 液压泵站（主泵、辅助泵）、空压机、水路系统 | 柴油机/电动机 → 液压泵 |
| **钻臂（机械臂）** | 支撑凿岩机构并把它定位到断面任意孔位 | **液压缸（变幅/摆动/伸缩）+ 液压马达（回转）** |
| 推进机构 | 推进梁（铝合金/钢制导轨）+ 推进器 | 链条/油缸/液压马达推进，推进力可达 18 吨级 |
| 回转机构 | 回转头带动钎杆旋转 | 液压马达，0–200 rpm，扭矩数百至上千 N·m |
| 凿岩机 | 冲击活塞、配流阀、钎尾 | 液压（或气动）冲击，功率 20 kW 级，频率 40–50 Hz |
| 电控系统 | 控制器、比例阀驱动、传感器、人机界面、网络上传 | 电液比例控制 + 编码器/压力闭环 |

参考资料：[隧道凿岩液压钻机百科](https://b2bwiki.baidu.com/encyclopedic/tunnel-hydraulic-rock-drill)、[凿岩车液压油缸结构](https://b2bwiki.baidu.com/encyclopedic/rock-drill-hydraulic-cylinder)、[液压凿岩台车概述（SlideShare）](https://www.slideshare.net/slideshow/hydraulic-drill-jumbos-an-overview/27324764)

### 1.2 钻臂的"机械臂"本质：自由度与驱动元件

钻臂本质上是一台**液压驱动的高冗余度串联机械臂**，学术建模常用 **6R-2P** 或 **8 自由度（8R）** 模型：

- **R（转动关节）**：均由液压缸驱动（动力学上等效为 RPR 结构）。典型布置：
  - 变幅油缸 ×2 —— 大臂俯仰（上下摆动，耿力 G1Z70 可达 ±45° 摆动范围）
  - 摆臂油缸 ×2 —— 大臂左右回转
  - 推进梁俯仰缸、推进梁摆动缸 —— 调整推进梁姿态（打平孔/斜孔/立孔）
  - 推进梁翻转机构（回转马达或齿轮齿圈）—— 推进梁 360° 翻转，用于打周边孔
- **P（移动关节）**：
  - 大臂伸缩段（部分机型，如耿力 G3ZE 工作臂伸缩 1600 mm）
  - 推进器沿推进梁的滑移 —— 即钻杆进给
- **补偿油缸**：钻臂到位后将推进梁顶紧岩面（承载 18 吨级反力），是保证钻孔直线度与防卡钎的关键，也是"钻孔前锁定基座"的物理约束。
- **回转马达**：驱动钎杆旋转，配合凿岩机冲击破岩。

液压驱动回路要点：电液比例换向阀（开环→闭环控制缸/马达速度）+ 平衡阀/液压锁（负载保持与防坠落）+ 压力切断与防冲击缓冲。油缸典型结构：缸筒-活塞-42CrMo 镀铬活塞杆-导向套-密封缓冲（见[液压油缸百科](https://b2bwiki.baidu.com/encyclopedic/rock-drill-hydraulic-cylinder)）。

臂架结构形式（单臂/伸缩臂/折叠臂）可参考专利 [WO2014202006A1 凿岩机伸缩臂及凿岩机](https://patents.google.com/patent/WO2014202006A1/zh)。

### 1.3 控制系统的感知与控制链路

```
上位控制（工控机/PLC + HMI）
   │  目标孔位（来自设计炮孔布置图 / 平台下载）
   ▼
运动学解算（逆解：孔位坐标 → 各关节液压缸目标行程/角度）
   │
   ▼
电液比例阀放大器 ──► 变幅缸/摆臂缸/翻转马达/推进缸/回转马达
   ▲                                     │
   │  反馈                                ▼
角度编码器/倾角传感器/拉线位移计/压力传感器 ◄── 凿岩参数(冲击/推进/旋转/水压)
```

自动钻孔闭环（学界主流做法）：
1. **正逆运动学建模**：D-H 法建立 8 自由度坐标系，逆解出各油缸目标值（见论文清单 4.1）；
2. **孔序规划**：多臂协调 + 孔序优化（蚁群/灰狼算法等）减少空行程；
3. **自动寻孔**：传统逆解分层控制 vs 强化学习端到端控制（见 4.2 英文文献）；
4. **钻进过程控制**：推进压力/回转压力自适应调节，防卡钎，同时按规范采样冲击压力、推进压力、推进速度、旋转压力、水压等过程数据。

### 2.2 与控制系统研发相关的要点

1. **G3ZI 全电脑三臂**和 **G2Z-D 电脑导向两臂**是耿力"电脑控制钻孔"路线的代表——即我们要自研的控制系统的同类产品形态：自动布孔、大臂自动定位、按设计孔图钻凿并回传数据。
2. **G1Z70 单臂**最适合作为控制系统首台样机载体（结构简单、boomId=1，与接口规定"单臂台车大臂编号填 1"直接对应；单臂台车 2–4 m 小断面场景施工记录见[小断面凿岩台车解析](https://b2bwiki.baidu.com/article/704656176276258817)）。
3. **GL18T 液压凿岩机**（最大液压压力 23 MPa、冲击 20 kW）是自研液压系统设计的对标参数：接口规定要求的冲击压力/推进压力/旋转压力传感器量程应按 23 MPa 级（≈230 Bar）选型。
4. 耿力 2026 年新获专利[《凿岩台车铰接式卷筒液压控制系统》CN224786046U](https://www.soopat.com) —— 卷缆液压控制，底盘部分可参考。
5. 若项目扩展锚杆作业，**GMZ12I 智能锚注一体机**就是锚注接口规定的目标设备形态（预应力/扭矩/注浆量采集）。

## 3. 与《数据接口暂行规定》的对接关系

钻臂驱动装置 → 控制系统 → 平台接口的字段映射：

| 机械/驱动量 | 传感器 | 接口字段（凿岩台车规定） |
| --- | --- | --- |
| 各油缸行程/角度 → 运动学正解 | 角度编码器/倾角仪/拉线计 | start/end X/Y/Z（掌子面坐标系，SM4 加密） |
| 推进器行程 | 推进长度传感器 | holedepth 当前孔深（50cm 采样，末段 5cm） |
| 冲击油压 | 压力传感器 | barctpre 冲击压力 (Bar) |
| 推进油压 | 压力传感器 | propupre 推进压力 (Bar) |
| 回转油压 | 压力传感器 | rotationpre 旋转压力 (Bar) |
| 推进速度（推进缸速度） | 速度/位移微分 | propuspeed (m/min) |
| 供水压力 | 压力传感器 | waterpre (Bar) |
| 整机定位 | 全站仪/惯导/电脑导向 | machlocation、origin（X#Y#Z） |
| 大臂编号 | 配置 | boomId：左1/中2/右3，单臂=1 |
| 时间基准 | 平台对时接口 | starttime/endtime、cjtime |

## 5. 下一步工作建议

1. **确定样机机型**：建议以单臂（对标 G1Z70）起步——自由度少、boomId 固定为 1，先打通"设计下载 → 自动寻孔 → 过程数据采集 → 平台上传"全链路，再扩展多臂。
2. **运动学建模**：按 6R-2P / 8-DOF 模型做 D-H 建模与逆解（先读 4.2 前 3 篇英文 + 4.1 八自由度两篇）。
3. **液压系统对标**：参考 GL18T（23 MPa）确定传感器量程与比例阀选型；调平与补偿回路参考《凿岩台车自动调平电液系统研究》。
4. **数据接口**：按已整理的《接口规定整理与分析.md》实现 SM4/DES 加密、JWT 登录、断点续传上传。
5. **CNKI 精确检索式**：`主题=("凿岩台车" OR "钻臂") AND ("运动学" OR "轨迹规划" OR "自动钻孔")`，硕博论文重点看烟台大学、安徽理工大学等学位论文。
