## 1. 项目范围与设计目标

### 1.1 钻孔定位系统是什么

钻孔定位系统 = 让钻臂**自动把钻头送到掌子面上指定孔位、并对准指定孔轴方向**的整套控制系统。它是"自动钻孔"的前半段；后半段（钻进过程控制）在本版只做数据采集预留。

一次完整的定位-钻孔循环：

```
接收设计炮孔清单 → 台车定位/坐标系建立 → 逐孔：大臂自动寻孔定位
  → 推进梁顶紧(补偿) → 开孔 → 钻进(按50cm采样) → 终孔退钎 → 下一孔
  → 循环结束：成果数据组包上传平台
```

### 1.2 设计输入（来自已读资料）

| 输入 | 内容 | 来源 |
| --- | --- | --- |
| 孔位目标 | 设计炮孔清单（孔编码/孔号/孔深/孔类型/起止点坐标） | 接口规定 表3-3-2 下载钻孔设计参数 + 炮孔布置文件 |
| 坐标基准 | 掌子面坐标系 + 原点 origin（工程坐标，X#Y#Z，SM4 加密） | 接口规定 表3-2-1 |

| 液压参数对标 | 冲击功率 20kW、频率 40–50Hz、最大液压压力 23MPa（≈230Bar）、回转扭矩 820N·m、大臂摆动 ±45° | 耿力 G1Z70 / GL18T 实测参数 |

### 1.3 版本策略：为什么从单臂做起

- 单臂自由度少、无多臂干涉问题，运动学/控制问题最纯，适合把**全链路**先打通；
- 接口规定对单臂友好（boomId 恒为 1，无臂间孔序协调）；
- 单臂模型验证后的运动学内核、液压控制回路、数据采集框架，可直接复制扩展到多臂。

## 2. 被控对象：钻臂机构分析

### 2.1 机构组成与等效自由度

单臂钻臂的机构链（从车体到钻头）：

```
车体(回转支承/摆臂基座)
 └─ J1 大臂回转(摆臂)   水平面内左右摆        摆臂油缸×2      θ1 ∈ [-45°, +45°]（对标G1Z70）
 └─ J2 大臂变幅(俯仰)   铅垂面内俯仰          变幅油缸×2      θ2 ∈ [-10°, +55°]
 └─ J2b 大臂伸缩        沿臂轴伸缩            伸缩臂油缸      d1 ∈ [2.0, 5.8] m（对标G3ZE伸缩结构）
 └─ 推进梁座(大臂头部)
     └─ J3 推进梁摆动   左右偏摆              摆梁油缸×2      θ3 ∈ [-45°, +45°]
     └─ J4 推进梁俯仰   上下俯仰              俯仰油缸×2      θ4 ∈ [-100°, +100°]
     └─ (J5 翻转       绕梁轴 360° 翻转       翻转马达/齿轮    V0.1 固定 0°，打周边孔时启用)
     └─ J6 推进(滑移)   钻具沿梁轴移动         推进油缸/链     d2 ∈ [1.2, 5.8] m
     └─ 钻头 tip
```

要点：
1. **驱动全部是液压**：转动关节由双油缸对驱动（等效为转轴），伸缩/推进由油缸（或马达+链条）。所以 PLC 的执行层本质是**控制若干电液比例阀**。
2. **补偿油缸不是自由度**：定位完成后把推进梁顶紧掌子面（反力 18 吨级），钻孔期间机构被"锚固"，它属于安全支承回路（§5.4）。
3. **自由度数**：活动关节 6 个（J1、J2、J2b、J3、J4、J6）= **4R + 2P**。定位任务约束 5 个（孔位 3 + 孔轴方向 2）→ **1 维冗余**（大臂伸缩与推进如何分配），由 DLS 最小范数解自然分配；V0.2 可改为显式评价函数（能耗/耗时最优）。
4. **为什么必须有伸缩臂（V0.1 调试结论）**：固定长度大臂的头部只能在半径固定的球面上，无法配合推进覆盖整个断面；伸缩臂补足"臂长-孔距"差。这是仿真验证出的硬结论，选型时伸缩行程按断面尺寸反推。

### 2.2 传感配置（定位闭环的反馈量）

| 关节 | 传感器 | 量程参考 | 用途 |
| --- | --- | --- | --- |
| J1/J2/J3/J4 | 角度编码器（绝对式多圈）或双倾角仪 | ±180°，0.01° 级 | 运动学正解、定位闭环 |
| J6 推进 | 拉线位移计 / 磁致伸缩尺 | 0–5 m，1 mm 级 | 孔深、采样触发 |
| 各油缸大/小腔 | 压力变送器 | 0–250 Bar（对标 23MPa 凿岩机） | 接口上传 + 防卡钎预留 |

## 3. 系统总体架构

```
┌────────────────────────────────────────────────────────┐
│  HMI 司机室触摸屏：孔位图/状态/手动干预                    │
├────────────────────────────────────────────────────────┤
│  上位工控机(定位控制器)                                   │
│   · 设计数据解析(SM4解密)  · 运动学解算(FK/IK)            │
│   · 状态机(自动寻孔流程)   · 数据记录/组包上传(CRBIMS)     │
├────────────────── 实时以太网/CAN open ───────────────────┤
│  PLC(实时执行层)                                         │
│   · 比例阀电流环/PID位置环  · 联锁与安全逻辑              │
│   · 高速计数(编码器)  · 模拟量采集(压力)  · 对时          │
├────────────────────────────────────────────────────────┤
│  执行/感知层                                             │
│   比例换向阀→油缸(×8) · 翻转/回转马达 · 推进马达           │
│   角度编码器×4 · 位移计 · 压力传感器×6 · 流量计            │
└────────────────────────────────────────────────────────┘
        │ 4G/工业WiFi(隧道内需AP布网)
        ▼
   铁路工程管理平台 CRBIMS（接口规定定义的 6 类接口）
```

分层职责划分原则：**PLC 只做"快速、确定性"的事**（阀控制、限位联锁、模拟量采集，ms 级）；**工控机做"聪明、慢"的事**（运动学、路径规划、通信，100ms 级）。这一划分使后续换 PLC 品牌只动执行层。

## 4. 坐标系定义与转换（对接接口规定）

定义 4 层坐标系（V0.1 先建前 3 个，整机定位标定后启用第 4 个）：

```
{W} 工程坐标系     项目统一坐标（接口规定 machlocation/origin 用）
 {V} 车体坐标系    原点=车体回转中心投影点，X前(指向掌子面) Y左 Z上
  {B} 大臂基座系    原点=摆臂轴线与大臂轴线的交点，固定偏置安装于车体
   {T} 工具系(钻头)  X=钻进方向，原点=钻头尖
```

- 设计炮孔坐标从平台下载后是**掌子面坐标系**（原点=origin，接口规定上传字段）。V0.1 仿真中直接把 {W} 简化为掌子面系。
- 转换链：`p_掌子面 →(T_VW)→ p_车体 →(T_BV 固定安装偏置)→ p_大臂基座 →(FK)→ 钻头`。
- **孔轴方向**：爆破孔默认垂直掌子面（方向 = 掌子面法向），周边孔/掏槽孔按设计文件带外插角。逆解时方向约束来自设计数据 endX/Y/Z − startX/Y/Z。

## 5. 运动学建模与求解（已代码化）

详见 `src/jumbo_kinematics.py`，原理：

### 5.1 正运动学 FK

采用连杆变换链（非标准 D-H 表，便于混合 R/P 关节与直观几何参数）：

```
T_tip = Trans(B) · Rz(θ1) · R(-y,θ2) · Trans(d1,0,0) · Rz(θ3) · R(-y,θ4) · [Rx(0)] · Trans(d2,0,0)
        基座      摆臂      变幅        大臂伸缩      梁摆动   梁俯仰     翻转固定   推进
```

工具轴方向 = T 的 X 列（钻进方向，指向掌子面）。参数集中在 `JumboParams`，**换机型只改参数字典**。

### 5.2 逆运动学 IK

数值解（阻尼最小二乘 DLS），不依赖具体构型的解析解：

```
残差 e(q) = [ p_target − p_tip (3) ;  axis_des − axis_cur (3) ]
            ↑ 位置误差用"期望−实际"        ↑ 方向残差必须用差向量：
              才沿雅可比下降方向              叉积对 180° 反向不敏感，
                                            会把钻轴指反还以为对准了
迭代 q ← q − Jᵉᵀ(JᵉJᵉᵀ+λ²I)⁻¹ e ，Jᵉ=∂e/∂q 数值雅可比，关节限位投影，λ=0.05，随机重启
```

好处：改自由度配置（加伸缩臂/启用翻转）只需改关节表，算法不动——为多臂升级留了路。收敛判据：位置误差 <0.5mm、方向误差 <0.057°。

### 5.3 验证结果（V0.1 实测运行输出）

`demo_positioning.py` 在 6.0×4.6m 掌子面（基座至面 5.2m）取 5 个代表孔（中心/三角/两角/斜孔）：

| 孔 | 类型 | 位置误差 | 方向误差 | 备注 |
| --- | --- | --- | --- | --- |
| H1 中心 | 辅助孔 | 0.28 mm | 0.008° | PASS |
| H2 上角 (2.8, 4.2) | 周边孔 | 0.50 mm | 0.017° | PASS，解在摆臂/梁摆限位附近 |
| H3 下角 (−2.8, 0.8) | 周边孔 | 0.02 mm | 0.002° | PASS |
| H4 角部 (−3.0, 3.6) | 周边孔 | 0.50 mm | 0.014° | PASS |
| H5 斜孔 ~20° | 掏槽孔 | 0.25 mm | 0.008° | PASS |

可视化输出 `src/jumbo_ik_demo.png`（钻臂 3D 构型 + 掌子面孔位图）。角部孔解贴限位是正常现象：垂直孔要求梁摆角抵消大臂摆角（θ1+θ3≈0、θ2+θ4≈0），角部孔两角同时接近极限。

### 5.4 可达域与安全可达性（工程上的真约束）

V0.1 推得的**断面覆盖规则**（垂直孔、摆臂 ±45°）：
- 梁摆动必须抵消大臂摆角才能打垂直孔 → 基座到梁枢的**水平距离 ≥ 横向偏移 / tan(摆角极限)**——横向摆角限位直接决定断面半宽；
- 伸缩臂必须能补足"基座到(孔位−推进余量)"的长度差 → 伸缩行程按断面最大斜距反推；
- 据此本配置（伸缩 2.0–5.8m）验证的可达断面为 **6.0m × 4.6m**；全断面（如 10.7×8.45m，G1Z80 标称）需更长伸缩/双臂分担。

后续加入的评价函数：
- 多解时选关节行程/耗时最小的构型（冗余分配显式化）；
- 姿态约束：仰角过大（>55°）时推进梁稳定性差 → 软限位；
- 补偿油缸行程不足（梁端距掌子面 > 补偿长度 ~1.5m）→ 该孔不可钻，需先挪车。

## 6. 液压驱动系统设计（原理级）

### 6.1 动力回路

```
油箱 → 齿轮泵/柱塞泵(主泵，电机/柴油机驱动) → 多路阀组
        ├── 比例换向阀×4(组) → J1~J4 油缸对（定位回路，闭环）
        ├── 比例换向阀×1    → 推进油缸/马达（钻进回路，压力/速度闭环）
        ├── 凿岩机冲击回路   → 独立高压(23MPa 级，GL18T 对标)
        ├── 补偿回路        → 补偿缸 + 液控单向阀(保压锁紧)
        └── 回转马达回路    → 钎杆旋转
```

### 6.2 定位回路（J1–J4）设计要点

| 要点 | 方案 | 原因 |
| --- | --- | --- |
| 阀选型 | **电液比例换向阀**（4WRA/4WREE 类），±10V 或 4–20mA 控制 | 定位需要速度连续可调；开关阀只能做点位冲击式运动 |
| 负载保持 | 每缸油口加**液压锁（双液控单向阀）** | 断电/断泵时大臂不得下沉——安全第一 |
| 重力平衡 | 大臂变幅缸无杆腔加**平衡阀** | 大臂自重远大于摩擦力，防超速失速 |
| 闭环结构 | PLC 模拟量输出→比例阀放大器→阀→缸→编码器→PLC 高速计数→定位FB → 修正输出 | 位置环在 PLC，10ms 周期；FB 见 `src/plc_st/FB_AxisPos.scl` |
| 死区补偿 | **叠加式**：给定 u 叠加 +dz 偏置抵消阀死区（全程线性）；带内不补偿防爬行 | ⚠ 不能用"小信号顶到死区值"的替换式——会给执行器最低速度(≈7°/s)，减速段停不下来（SIL 实测教训） |
| 速度前馈 | k_vff=1/满开比速，取自**转换后行程给定差分** | 纯 P 跟踪有 u/kp 稳态滞后；前馈差分自动含局部非线性当量 |
| 关节空间限幅 | 斜坡限速/到位带宽都在**关节空间**，经标定表转换到行程 | 行程当量非线性 ±20%，行程空间限速会饱和滞后 0.9°（SIL 实测教训） |

### 6.3 油缸 ↔ 关节角映射（V0.2 已代码化：`src/cylinder_mapping.py`）

平面铰点模型：基座铰点 B（半径 r_b、方位 α_b）+ 连杆铰点 A（半径 r_a、连杆系方位 β），缸长 l(θ)=|A−B|。V0.2 结论：
- **双缸是并排布置**（垂直于机构平面偏置），两缸行程相同——不能建平面镜像（会一伸一缩，均值无意义）；
- **关节跨度 >180° 窗的关节（梁俯仰 ±100°）单缸直驱必然非单调**，须四连杆放大（lever_k=2，油缸驱动曲柄 φ=θ/2）；
- 标定产物 = **60 点标定表 + 线性插值**（PLC 主用，往返误差 0.0000°），多项式拟合仅备份（反拟合误差 0.1°~0.7°，不可依赖）；
- 铰点尺寸为占位示意值，机构图纸到位后只改 Anchors 参数重标。

### 6.4 参数基线（对标 GL18T/G1Z70）

- 系统额定压力：定位回路 18–20 MPa，冲击回路 23 MPa；
- 定位油缸缸径 80–100 mm 级、行程 400–800 mm 级（具体待机构图纸）；
- 比例阀通径 NG6/NG10，响应时间 <50 ms；
- 定位单关节角速度设计值 ~10°/s（快速寻孔）→ 到位前减速段 2°/s（保证 0.1° 级到位精度）。

### 7.3 定位闭环控制结构（单关节）

```
工控机下装目标角 θ* ──► [PLC 定位FB]
                          │ 误差 e = θ* − θ
                          │ P(+前馈) → 阀给定 u，斜坡限幅
                          │ 死区补偿、低速到位判断(→夹紧/报到位)
                          ▼
                  AO → 比例阀 → 油缸 → 编码器 → HSC → 反馈 θ
```

V0.1 用 P + 斜坡前馈即可（比例阀+液压缸本身近似一阶惯性，P 足够稳定）；震荡再降增益或加 D。**整定留给台架阶段**，仿真阶段在 Python 里做关节级轨迹仿真先行验证减速曲线。

**软件在环（SIL）验证结果（2026-11-03，变幅关节全链路）**：轨迹(关节) → 关节空间斜坡 → 标定表转换 → 比例阀(死区0.5V) → 油缸(缸径90/20MPa/40L/min) → 行程反馈闭环：

| 工况 | 指标 | 结果 |
| --- | --- | --- |
| 阶跃 20° | 到位误差 / 超调 / 整定 | **0.030° / 0% / 1.1s**（判据 <0.05°/<5%） |
| 跟踪 PTP −10°→+55° | 动态峰值 / 终态误差 | **0.093° / 0.028°**（终态判据 <0.1°） |

整定值（kp=120 V/m、k_vff=24.4 V·s/m、带宽 0.03°）作为 PLC 版首装参数；台架阶段按实测阀死区/流量重标。

### 7.4 安全联锁（必须写死在 PLC，不依赖工控机）

1. 急停回路（硬线）：切断比例阀使能 + 泵卸荷，液压锁保位；
2. 硬限位 > 软限位：软限位由工控机轨迹规划遵守，硬限位由 PLC 直接断动作输出；
3. **补偿未到位禁止开孔/推进**（压力开关+行程双确认）；
4. 推进压力越上限 → 自动退钎（防卡钎基础版）；
5. 油温高/液位低/滤堵 → 禁止启动+报警。

## 8. 自动寻孔流程状态机

```
S0 待机 ──收到孔表──► S1 逐孔循环
S1 取第 i 孔(坐标/方向/孔深/类型)
S2 IK解算 → 可达? ──否──► S2E 标记不可钻/请求挪车 → 下一孔
S3 多关节协调运动(点到点+梯形速度规划,关节限位+碰撞软约束)
S4 到位校验(重解FK,位置<±10mm 且角度<±0.2°?) ──否──► S3 微调(最多3次)
S5 补偿缸顶紧(压力到位) → 锁定
S6 开孔(低速低推力 5cm) → S7 正常钻进(50cm采样;末段5cm;防卡钎监测)
S8 终孔(深度到位) → 退钎 → 补偿释放 → 记录成果(holesjdata) → S1 下一孔
S9 全部完成 → 组包上传(CRBIMS) → S0
任何状态: 急停→S_E (记录断点,恢复时从断点续)
```

对应接口字段的产生点已在 §1.2 表中标明——**状态机每一步的输出就是接口规定要的数据**，这是把"控制设计"和"平台对接"焊在一起的枢纽。
