## A. 液压基础

### A1. 为什么凿岩台车全用液压

同等功率下液压执行器体积/重量远小于电机，且天然抗冲击、过载自保护（溢流阀限压）、无级调速容易。凿岩工况是"重载+冲击+粉尘+潮湿"，液压系统是行业唯一成熟选择。

### A2. 四大件与功率三要素

```
动力:液压泵(齿轮泵/柱塞泵) → 控制:阀(方向/压力/流量) → 执行:油缸/马达 → 辅件:油箱/滤/管路/冷却
```

- 压力 p（MPa/Bar，1 MPa = 10 Bar）：由**负载**决定，泵只决定能顶到多高（溢流阀设定）；
- 流量 q（L/min）：由泵/阀开度决定，决定**速度**；
- 功率 P = p·q。液压推力 F = p × 缸面积：缸径 90mm 缸在 20MPa 下推力 ≈ 20e6 × π×0.045² ≈ **127 kN ≈ 13 吨**——这就是为什么变幅/摆动用双缸对。

**本项目用处**：估算各油缸推力→选缸径；系统压力 23MPa 对标 GL18T；压力传感器量程 0–250 Bar 的由来。

### A3. 阀的三类（控制设计的核心）

| 阀 | 作用 | 本项目使用 |
| --- | --- | --- |
| 方向阀 | 决定油流向 A 还是 B（缸伸出/缩回） | 比例换向阀（开度连续 0-100%→速度连续可调） |
| 压力阀 | 溢流(限压)/减压/平衡 | 系统溢流阀=安全上限；平衡阀=防大臂下坠 |
| 流量阀 | 节流调速 | 比例阀开度本身即调速，无需单独节流 |

**比例阀 vs 开关阀**：开关（电磁）阀只有通/断，只能"呼一下到位"；定位系统要**速度规划与精确到位**，必须比例阀（给定 ±10V/4-20mA，阀芯位移与给定成比例）。这是定位精度的硬件前提。

### A4. 三个必须懂的安全阀件

1. **液压锁（双液控单向阀）**：装缸的 A/B 口。断电断泵时油被封死在缸内 → **大臂不掉**。定位关节必装。
2. **平衡阀**：装在重载下降侧。既锁又防"负负载失控"（大臂下落越走越快）。变幅缸必装。
3. **溢流阀**：系统压力天花板，所有元件的保命符。

### A5. 凿岩三作用与过程数据对应

| 凿岩动作 | 液压来源 | 采集字段（接口规定） |
| --- | --- | --- |
| 冲击 | 冲击活塞被高压油往复打击钎尾（20kW/40-50Hz） | barctpre 冲击压力 |
| 旋转 | 回转马达带动钎杆（0-200rpm） | rotationpre 旋转压力 |
| 推进 | 推进缸/链条把钻具压向孔底 | propupre 推进压力、propuspeed 推进速度 |
| 排渣 | 高压水从钎杆中心孔喷出 | waterpre 出口水压 |

**防卡钎逻辑**（钻进控制的核心经验法则）：卡钎征兆 = 回转压力↑ + 推进速度↓。基础策略：rotationpre 超阈值 → 停推进甚至退钎；恢复正常再推进。V0.1 只做监测报警，V0.2 做自动干预。

### A6. 补偿回路（定位系统的"地基"）

钻臂定位后，补偿缸把推进梁**顶紧掌子面**（18 吨级），随后钻进反力全部由岩面-梁-车体传力路径承担，钻臂不再受力变形。控制上：
- 顶紧用**压力控制**（到设定压力即停），不是行程控制；
- 用压力开关 + 液控单向阀保压 → PLC 采"补偿到位"信号作为**允许开孔联锁**（总体设计 §7.4-3）。

## B. PLC 基础

### B1. PLC 是什么、为什么用它不用工控机直控

PLC = 工业实时控制器：**扫描周期**（读输入→运算→写输出，循环，10ms 级）确定性执行，抗振动宽温，IO 硬件丰富。定位阀控回路是 ms 级实时任务，必须 PLC；工控机跑运动学这种"算得慢但聪明"的任务。分工见总体设计 §3。

### B2. 学习路线（针对本项目定制，约 2-3 周）

```
第1周 入门:
  B2.1 扫描周期/梯形图LAD/结构化文本SCL 语法(变量、IF/FOR/CASE)
  B2.2 开发环境: TIA Portal + PLCSIM 仿真器(不买硬件也能学)
  B2.3 做题: 电机启保停、星三角、红绿灯顺序控制 → 都是为状态机打底
第2周 本项目相关专项:
  B2.4 模拟量: 4-20mA 物理意义、量程换算(压力传感器 4mA=0Bar, 20mA=250Bar)
  B2.5 高速计数 HSC: 编码器 A/B 相计数 → 角度
  B2.6 模拟量输出 AO: 给比例阀 ±10V 给定
  B2.7 PID 指令(FB): 用 PLCSIM 仿真一个一阶对象练 P/PI 整定
第3周 工程化:
  B2.8 状态机编程法(CASE OF) → 直接写 §8 寻孔状态机
  B2.9 安全程序: 急停链、使能链
  B2.10 与上位机通讯(Profinet/OPC UA 或 TCP)
```

### B3. 三个马上要用的代码模式（SCL 风格示意）

**① 模拟量换算（压力采集）**

```pascal
// 0-27648 原始值 对应 4-20mA 对应 0-250 Bar
pressure_bar := INT_TO_REAL(raw) / 27648.0 * 250.0;
```

**② 单关节定位 FB（P 控制 + 斜坡 + 死区补偿 + 到位判断）**

```pascal
FUNCTION_BLOCK FB_AxisPos
VAR_INPUT  target : REAL;  actAngle : REAL;  enable : BOOL;  END_VAR
VAR_OUTPUT done : BOOL;  valveCmd : REAL;  END_VAR
VAR_IN_OUT  axis : sAxisCfg;  END_VAR   // 增益/死区/限幅/斜坡等参数
VAR err, u : REAL;  END_VAR

IF NOT enable THEN valveCmd := 0.0; done := FALSE; RETURN; END_IF;

err := target - actAngle;
// 斜坡限幅：把目标逼近值限速，等效速度规划(简单可靠版)
axis.rampTarget := RAMP(target, axis.rampTarget, axis.vMax*dt, axis.aMax);
err := axis.rampTarget - actAngle;

u := axis.kp * err;                       // P 控制
IF ABS(u) < axis.deadzone THEN            // 死区补偿: 叠加最小起动作电压
    u := SIGN(err) * axis.deadzone;
END_IF;
valveCmd := LIMIT(-10.0, u, 10.0);        // 限幅到阀给定范围
done := (ABS(err) < axis.tol) AND (ABS(err) < axis.tol);  // 连续N周期判稳后置位
END_FUNCTION_BLOCK
```

（工程版需加"到位连续 N 个周期去抖""故障超时"，此处示意为先。）

**③ 状态机骨架（CASE OF，§8 流程的 PLC 落地形式）**

```pascal
CASE step OF
  0: // 待机
     IF cmdStart THEN step := 10; END_IF;
 10: // 取孔+IK(结果由工控机经通讯写入 DB)
     IF ikValid THEN step := 20; END_IF;
 20: // 多关节定位: 4个FB_AxisPos 同时运行
     IF ax1.done AND ax2.done AND ax3.done AND ax4.done THEN step := 30; END_IF;
 30: // 补偿顶紧: 压力闭环
     IF compPressureOK THEN step := 40; ELSE IF timeout THEN alarm := TRUE; step := 99; END_IF; END_IF;
 40: // 开孔(限速限推) → 50 正常钻进 → 60 终孔退钎 → 70 下一孔/上传
 99: // 故障/急停处理
END_CASE;
```

### B4. PLC 品牌选择（回顾总体设计 §7.1）

学习阶段：**S7-1200/1500 + PLCSIM**（资料最多、仿真免费）；行业实机：EPEC 等 CODESYS 系移动控制器——好在 SCL≈CODESYS ST，学习成果可平移。三菱 FX5U 可作备选，概念完全相通，只是指令系统不同。

## C. 概念对照速查表（学到哪用到哪）

| 遇到的词 | 一句话解释 | 在本项目位置 |
| --- | --- | --- |
| 比例阀 | 给定电压↔阀芯开度成比例的阀 | 所有定位关节的执行入口 |
| 液压锁 | 断电封油、保持位置 | 大臂不下坠的保险 |
| 平衡阀 | 防负负载失控的下行节流+锁 | 变幅回路 |
| 补偿缸 | 把推进梁顶紧掌子面的缸 | 开孔联锁条件 |
| 冗余自由度 | 关节数>任务约束数的构型 | 本机 5=5 恰定；多臂机型>5 需优化选取 |
| FK/IK | 关节角→钻头位姿 / 孔位→关节角 | `src/jumbo_kinematics.py` |
| DLS(阻尼最小二乘) | 数值求逆解的标准算法，λ 防奇异 | IK 实现 |
| HSC | PLC 高速计数器，接编码器 | 关节角度反馈 |
| SCL/ST | PLC 结构化文本语言（类 Pascal） | §B3 代码、阶段 0c 工程 |
| 状态机 | 用"当前步+转移条件"组织流程 | 寻孔流程 §8 |
| 死区补偿 | 阀小给定不动作的软件补偿 | §B3-② |
| 防卡钎 | 回转压力↑→减推进/退钎 | 钻进过程控制 V0.2 |
